# Killian's Poppy Vault

Killian's client resource site: prompts, videos, answers, template boards and a direct line to Killian.
Live at https://killianward8-lab.github.io/vault/

One file, `index.html`, copied from Joey's getpoppy.ai/joey/vault (which is a copy of `prompt-library.html`
in Poppy's site repo). Pictures live in `assets/`.

- Killian's details (name, email, booking link) sit in `VREPS.killian` near the bottom of `index.html`.
- Prompts are the `P` list, videos the `V` list, boards the `BOARDS` list. Edit, commit, push. GitHub Pages
  updates in about a minute.
- New Poppy channel uploads come in from getpoppy.ai/api/vault-videos when that feed is up.
- getpoppy.ai's tracking.js is left out (it belongs to getpoppy.ai pages only).
